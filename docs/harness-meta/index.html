Comment Diderot applique le harness

Le harness est un contrat de méthode versionné. Des fichiers d'amorçage courts le rendent automatiquement découvrable par les agents qui savent lire les instructions du dépôt, sans le recopier dans un prompt géant.

La chaîne d'autorité

source autoritative → contenu Diderot → méthode contrainte par le harness

Le harness ne devient ni le manuel de mathématiques, ni le papier scientifique, ni l'expert du domaine. Il contraint la façon de cadrer, tracer, expliquer, revoir et transmettre le travail.

Pas de « méga prompt » monolithique

Diderot utilise une divulgation progressive : AGENTS.md ou CLAUDE.md charge le manifeste local, qui fixe un commit immuable du harness, puis l'agent ne lit que les contrats compagnons utiles à la tâche.

AGENTS.md / CLAUDE.md → harness-adoption.yaml → immutable harness ref → relevant companions

Le SKILL.md ajouté au dépôt harness n'est qu'un point d'entrée de compatibilité. La source normative reste HARNESS.md.

Ce qui peut être automatique

Codex / agents OpenAI travaillant dans le dépôt

Le fichier racine AGENTS.md sert d'amorçage. Il exige le chargement du manifeste et du commit épinglé avant tout travail substantiel.

Claude Code

Le fichier racine CLAUDE.md joue le même rôle. Si le harness est un jour vendored localement à un commit immuable, un import local explicite peut remplacer le chargement distant.

Chat générique

Un fichier GitHub ne peut pas forcer n'importe quelle surface de chat à ouvrir le dépôt. Lorsque le runtime ne découvre pas les instructions du repository, la configuration du Project, workspace ou agent doit charger le même bootstrap. Déclarer une dépendance et prouver qu'un runtime l'a chargée sont deux choses différentes.

Premier consommateur : le langage mathématique

mathematics/notation/registry.json capitalise les notations rencontrées : lecture orale, sens formel, phrase naturelle, exemple, prérequis, piège, provenance, nouvelles rencontres, connexions et domaines d'application.

Les agents peuvent détecter et proposer automatiquement une entrée ou une nouvelle rencontre, mais leurs ajouts restent draft jusqu'à revue. La page interactive et la planche A2 sont deux vues dérivées du même registre.

Meta-gouvernance

Une règle générique découverte dans Diderot doit remonter vers le harness. Une connaissance mathématique ou ML reste dans Diderot ou sa source autoritative. Ce découplage évite à la fois le prompt géant et le harness qui absorberait le contenu scientifique.

Entrées pratiques

  • harness-adoption.yaml — pin, autorité et artefacts locaux.
  • AGENTS.md — bootstrap des agents OpenAI/Codex.
  • CLAUDE.md — bootstrap Claude Code.
  • Atlas des notations mathématiques.
  • Planche A2 imprimable.
  • Source Markdown de cette méta-documentation.
Boundary
L'automatisation ne remplace pas la revue.

Le mécanisme vise à rendre l'oubli difficile : le bootstrap rappelle le contrat et le registre. Il ne transforme pas une explication générée par un modèle en vérité mathématique ni en preuve scientifique.
