No-jump decision pathway

From belief to adaptive decision sufficiency

Why knowing the current state better is not the same as knowing what to do, why an action is not a policy, why outcomes can be delayed, and why a compressed state may need to preserve future branches rather than only today's answer.

foundations + project refinementadded 2026-09-01
Boundary

Steps 1–10 teach established POMDP / decision / predictive-state concepts from cited literature. The final `contingent sufficiency` step is a project-local research hypothesis. The interactive lab is a deterministic teaching construction, not scientific evidence and not a successful Toy F2 result.

1

Hidden state vs observation

Start by separating what the system actually is from what the sensors reveal.

2

POMDP

Once state is hidden, sequential decisions must account for uncertainty and the way actions influence what can be observed later.

3

Belief state → Bayesian filtering

Compress relevant action-observation history into a posterior over current state; update it when new evidence arrives.

4

More certainty ≠ different decision

A sharper belief may remain on the same side of every relevant decision boundary. Certainty and decision value are therefore different quantities.

5

Action ≠ policy

The current action is one output. A policy specifies how choices will continue after future observations change the belief.

6

V and Q

Evaluate delayed consequences over a declared horizon rather than ranking actions by immediate payoff alone.

7

Epistemic action → value of information

A probe can be worth doing because its result changes later choices; information that changes no consequential branch may be worthless despite reducing uncertainty.

8

Contingent policy

Represent “if I observe x, do A; if I observe y, do B” rather than pretending tomorrow's evidence is already known.

9

Receding-horizon planning

Plan a bounded future, act once, observe, update and replan instead of materializing an exponentially large tree forever.

10

Predictive state vs belief

State can sometimes be expressed through action-conditioned predictions of future observable tests rather than through named hidden-state coordinates.

11

Sufficient state → decision regret

Declare what the representation must preserve, then measure the value lost when decisions use the compression instead of the reference information state.

12

Contingent sufficiency project hypothesis

Ask whether a compact state preserves the ability to continue adaptive decision-making over relevant future contingencies—not merely the current action.

13

Belief ≠ model ≠ memory

Keep current uncertainty revisable while separately governing learned dynamics and durable competence/provenance.

14

Evidence of non-regression

Protect old competence with bounded evidence or structural guarantees without claiming that a finite replay set proves global invariance.

Executable learning path

Open the Belief and adaptive planning lab. It contains three linked experiments: Bayesian update, more certainty with the same action, and same current action with different future contingent value.

What would weaken the project refinement?

The `contingent sufficiency` refinement should be narrowed if a fair construction cannot produce states that are identical for the declared immediate decision but materially different for future policy value; if the distinction is only a reward-definition trick; or if established state-abstraction/bisimulation terminology already captures the useful object more precisely. Those outcomes would not invalidate POMDP or value-of-information theory; they would invalidate or rename the project-specific refinement.
