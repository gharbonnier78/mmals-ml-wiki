Partially observable Markov decision process (POMDP)

A sequential decision model in which the relevant state is hidden and must be inferred from observations and action history.

foundational conceptadded 2026-08-30

Core objects

A POMDP adds an observation process to an MDP. The agent reasons over a belief distribution on hidden state rather than assuming direct access to the true state.

GO-ED relevance

GO-ED-POMDP treats the belief as an explicit decision object and extends attention to goals, evidence quality, missing evidence and the value/cost of acquiring more information.

MMALS relevance

Inferred context and regime inference naturally raise POMDP-like questions: what state is hidden, what observations support it, and how should uncertainty influence routing or regime creation?

Toy

Use a hidden machine-health regime with noisy sensors. The same observation can mean different things depending on the current belief, making the need for belief-state reasoning visible.
