State estimator

A mechanism that infers the current system state or a distribution over it from partial, noisy or indirect observations.

foundational conceptadded 2026-08-30

Examples

Kalman filters, particle filters, hidden-state neural encoders and Bayesian filters can all act as state estimators under different assumptions.

Encoder vs estimator

An encoder maps data to a representation. A state estimator carries a stronger semantic claim: the output is intended to represent the current dynamical state or belief relevant to future evolution.

MMALS relevance

Future MMALS should decide whether inferred context is merely a routing feature or a genuine state estimator. The distinction should be experimentally testable through predictive sufficiency.

Toy

Use a noisy position/velocity process where current position alone is insufficient. Compare an encoder using one observation with an estimator using temporal evidence.
