Observation model

A model linking hidden system state to the observations that sensors, measurements or data sources make available.

foundational conceptadded 2026-08-30
p(o_t\mid s_t)

Why it matters

Observations are not the state itself. Noise, missing data, ambiguity and sensor limitations can make several states compatible with the same observation.

GO-ED relevance

Evidence-driven decision making should track not only the observation value but also the source, reliability, representativity and uncertainty associated with the observation process.

MMALS relevance

Apparent novelty may originate in a changed observation process rather than a changed world regime. Regime detectors should therefore be stressed against sensor shift and missingness.

Toy

Keep the hidden dynamics fixed while changing sensor noise. A robust system should not automatically create a new world regime merely because the observation channel degraded.
