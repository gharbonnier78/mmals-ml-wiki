State and memory

Path dependence

Two systems with similar present observations can retain different future possibilities because they arrived there through different histories.

open hypothesisadded 2026-09-03

In plain language

Knowing where a system is now may not tell you everything that matters about what it can do next. Earlier adaptations can leave structural traces, constraints and reusable competence.

Engineering view

A current-state estimator may be sufficient for one prediction task while being insufficient for safe model adaptation. Selected history features can therefore belong to model governance or memory even when they are not needed by the immediate action policy.

Research view

The question is empirical: does a present summary contain all information required for the target prediction or decision? If not, history-sensitive structure must be represented somehow. This should be tested against stronger sufficient-state baselines before adding memory merely because history is available.

Formal anchor

same present summary does not always imply same future capability
open hypothesis
Current evidence

Evolutionary history provides biological examples of persistent inherited structure. Diderot already distinguishes belief, model and memory, but MMALS has not yet shown that explicit path descriptors improve a bounded benchmark.

Boundary

Path dependence is not a license to store the full history. A compact sufficient state remains preferable when sufficiency is demonstrated for the decision at hand.

Why it matters for MMALS

A host that has reached a current competence through one sequence of adaptations may have different non-regression obligations and fork risks from a host with the same current score reached by another route.

Misconception

Wrong: if history matters anywhere, every observation must be retained forever. Correction: retain only history-derived information whose predictive, causal, audit or competence-preservation value survives testing.

Understanding gate

Explain one situation where two models with the same current accuracy could require different next updates because their validated competencies or training trajectories differ.
