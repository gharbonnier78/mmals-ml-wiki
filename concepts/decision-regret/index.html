Evaluation of decision sufficiency

Decision regret

The expected value lost because a representation or policy chooses worse than a declared reference for the same decision problem.

metric bridgeadded 2026-09-01

Intuition

Prediction error asks whether a model forecast was numerically close. Decision regret asks whether the remaining error actually caused worse decisions.

R_H(z)=V_H^*(b)-V_H^{\pi_z}(b)

Concrete example

Two approximate beliefs can have the same probability error. If one stays on the same side of every relevant decision boundary while the other crosses a costly boundary, their decision regrets differ sharply.

Mathematical descent

Declare a reference information state b and a value criterion over horizon H. Compute the reference optimal value. Then force decisions to use representation z and compute the value of its induced policy. Their difference is regret relative to that reference and query.

In plain language

“How much did this representation cost us in the decision process?”

Misconception

Wrong: zero decision regret proves the representation contains all information about the world. Correction: it proves only that no value was lost for the declared decision problem, horizon, action set and reference model.

Understanding gate

Explain how a crude representation can have zero regret for one decision query yet be unusable for a different goal, horizon or action set.

Project boundary

The separate Toy A/F research uses posterior expected decision regret as an operational criterion. This Diderot page teaches the metric concept; it is not itself evidence for the research result.
