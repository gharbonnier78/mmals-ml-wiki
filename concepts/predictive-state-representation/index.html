State through predictions

Predictive state representation (PSR)

Represent the current state of a controlled stochastic system through predictions of future observable tests rather than by naming an unobserved latent state directly.

research literature conceptadded 2026-09-01

Intuition

Instead of storing “I am 70% in hidden state S₁ and 30% in S₂”, a predictive representation can store quantities such as “if I take this action sequence, what is the probability of seeing these future observations?”.

q_t=\big[P(\tau_1\mid h_t),\ldots,P(\tau_k\mid h_t)\big]

Concrete example

For three candidate tests, store the probability that each action-observation experiment succeeds from the current history. If those predictions contain all information needed to update future tests, they can act as state coordinates.

Mathematical descent

Start from history ht. Define observable future tests τ made of action/observation events. Predict their conditional probabilities. Select a sufficient set of such predictions as coordinates. A PSR update maps old predictions plus the executed action and new observation to new predictions.

In plain language

The state is described by what the system is predicted to do under carefully chosen future experiments.

Misconception

Wrong: any vector of next-observation probabilities is automatically a PSR sufficient for control. Correction: the selected predictions must collectively preserve the information needed to update and predict the relevant future tests.

Understanding gate

Explain the difference between (1) a hidden-state belief, (2) a one-step next-observation predictor, and (3) a predictive state built from enough action-conditioned future tests.

Authority
