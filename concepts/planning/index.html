Planning

Choosing actions by evaluating possible future consequences against an objective, constraint set or cost function.

general conceptadded 2026-08-30

Model-based planning

When a transition/world model is available, candidate actions can be simulated before execution. The quality of planning therefore depends on model validity, uncertainty and horizon.

ED-POMDP / goal-oriented extension relevance

Goal-oriented evidence-driven planning should ask not only which action looks best, but which evidence is missing, how uncertain the projected consequence is, and whether acquiring more evidence has option value. ED-POMDP is the project-specific Evidence-Driven POMDP programme; the GO-ED wording used in this wiki is a tentative goal-oriented extension, not an established external framework.

MMALS boundary

MMALS routing is not planning. Planning becomes relevant only when the system evaluates future consequences of alternative actions or architectural interventions.
