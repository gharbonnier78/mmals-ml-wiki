Planning

Choosing a decision rule by evaluating delayed and observation-dependent future consequences against an objective, constraints and uncertainty.

general conceptexpanded 2026-09-01

Intuition

Planning is not only “which action looks best next?”. In a partially observable problem it can compare adaptive policies whose later actions depend on evidence not yet observed.

Model-based planning

When a transition/world model is available, candidate actions or policies can be evaluated before execution. The quality of planning therefore depends on model validity, uncertainty, action coverage, horizon and the objective used to score consequences.

\pi^*=\arg\max_{\pi}\;V_H^\pi(b_t)

Delayed outcomes

An action can be locally costly and globally useful. A diagnostic may consume time now but improve a later repair decision. Conversely, a confidence-increasing measurement can be useless when all possible results lead to the same policy branch.

Adaptive loop

plan → act → observe → update belief → replan. Receding-horizon methods can implement this loop without materializing an enormous policy tree.

ED-POMDP / goal-oriented extension relevance

Goal-oriented evidence-driven planning should ask which evidence is missing, how uncertain the projected consequence is, and whether acquiring more evidence changes expected decision value. ED-POMDP is the project-specific Evidence-Driven POMDP programme; GO-ED remains a project extension rather than an established external framework.

MMALS boundary

MMALS routing is not planning. REUSE/ADAPT/FORK becomes a planning problem only if candidate architectural interventions are evaluated through future consequences, evidence acquisition and retained competence rather than used as labels for one local classifier.

Misconception

Wrong: an optimal plan predicts one perfect future trajectory. Correction: under uncertainty the relevant object can be an adaptive policy evaluated over possible observations and outcomes.

Understanding gate

Explain why the best first action can remain the same for two beliefs while the best finite-horizon contingent policies differ.
