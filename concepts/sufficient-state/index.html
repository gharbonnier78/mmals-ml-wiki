Sufficient state

A state representation that retains enough information from the past for a declared family of predictions or decisions. “Sufficient” is always relative to what must remain answerable.

foundational bridgeexpanded 2026-09-01

Intuition

A good state can forget details of the past that no longer matter. The danger is compressing so aggressively that two histories look identical now even though they lead to different consequential futures.

Concrete example

Two histories both recommend continue today. In one, an extra diagnostic can never change the later decision. In the other, the diagnostic separates repair from continue. A representation that stores only today's action is sufficient for that one immediate choice but insufficient for the larger adaptive decision process.

Three increasingly strong questions

Immediate-action sufficiency: does the state preserve the current argmax action? Value sufficiency: does it preserve action/policy values within tolerance? Sequential/contingent sufficiency: can future observation, update and replanning continue without material value loss over the declared horizon?

In plain language

Minimal state does not mean the smallest object that reproduces today's answer. It means the smallest object that preserves the distinctions required by the questions we have explicitly decided must remain answerable.

Misconception

Wrong: a one-bit representation that stores the current action is therefore an excellent world-model state. Correction: it may be sufficient for one immediate query while destroying prediction, uncertainty, evidence acquisition and future replanning.

Understanding gate

State the prediction/decision family, horizon and action set for which you are claiming sufficiency, then give one change to those declarations that could make the same representation insufficient.

MMALS question

Can MMALS retain compact state and memory while preserving competence, transition structure and uncertainty relevant to future adaptive decisions? The stronger project-local contingent sufficiency formulation remains a hypothesis pending dedicated qualification.
