Sufficient state

A state representation that retains enough information from the past for a declared family of predictions or decisions. “Sufficient” is always relative to what must remain answerable.

foundational bridgeexpanded 2026-09-02

Intuition

A good state can forget details of the past that no longer matter. The danger is compressing so aggressively that two histories look identical now even though they lead to different consequential futures.

Concrete example

Two histories both recommend continue today. In one, an extra diagnostic can never change the later decision. In the other, the diagnostic separates repair from continue. A representation that stores only today's action is sufficient for that one immediate choice but insufficient for the larger adaptive decision process.

Three increasingly strong questions

Immediate-action sufficiency: does the state preserve the current argmax action? Value sufficiency: does it preserve action/policy values within tolerance? Sequential/contingent sufficiency: can future observation, update and replanning continue without material value loss over the declared horizon?

Context window is not the state definition

An agent may have access to a large transcript, document store or external memory without placing all of it in the active model context at every step. The context window is an implementation resource: a working set supplied to an inference mechanism. The decision-theoretic question is different: what information state must be available now so that the declared predictions, actions and future updates remain adequate? Retrieval can therefore reintroduce selected historical evidence when the compact current state is not sufficient by itself.

Belief or one best state?

Under a correctly specified POMDP, the belief state is the classical Markov information state for planning because it retains uncertainty over the hidden state. A single best-state estimate is a stronger compression. It can be adequate when the discarded uncertainty cannot materially change the relevant decision or future value, but that adequacy must be justified for the declared goal, horizon, action set and cost model rather than assumed.

Goal and regime change what “enough” means

Sufficiency is also objective-relative. The same representation can be adequate for a low-consequence immediate action and inadequate for a safety-critical or resource-constrained mission. If operating conditions change the available actions, costs, observations or acceptable regret, they can also change which distinctions the state must preserve. If the regime itself is hidden, the decision system cannot legitimately condition on the unknowable true regime; it must use observable mission context, a belief over regimes, or another justified information state.

In plain language

Minimal state does not mean the smallest object that reproduces today's answer. It means the smallest object that preserves the distinctions required by the questions we have explicitly decided must remain answerable.

Misconception

Wrong: a one-bit representation that stores the current action is therefore an excellent world-model state. Correction: it may be sufficient for one immediate query while destroying prediction, uncertainty, evidence acquisition and future replanning.

Understanding gate

State the prediction/decision family, horizon, action set and cost model for which you are claiming sufficiency, then give one change to those declarations that could make the same representation insufficient. Explain separately whether the agent needs the complete history in active context or only a sufficient information state plus recoverable memory.

MMALS question

Can MMALS retain compact state and memory while preserving competence, transition structure and uncertainty relevant to future adaptive decisions? The stronger project-local contingent sufficiency formulation remains a hypothesis pending dedicated qualification.
