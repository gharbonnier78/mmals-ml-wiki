Bifurcation

A qualitative change in dynamical behavior caused by a change in parameter or condition, without necessarily changing the governing model family.

foundational conceptadded 2026-08-30

Why it matters

A new stable state, oscillation or instability can emerge when a parameter crosses a threshold. Novel behavior therefore does not automatically imply an entirely new mechanism or model.

MMALS relevance

Before creating a new host or regime, test whether the observation can be explained as parameter drift or a bifurcation inside an existing dynamical family.

Toy

Use a one-parameter nonlinear system whose equilibrium changes stability. Compare parameter adaptation with unnecessary model expansion.
