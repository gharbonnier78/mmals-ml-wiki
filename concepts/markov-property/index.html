Markov property

Given a sufficient current state, the modeled future is conditionally independent of the earlier history.

foundational conceptadded 2026-08-30
P(s_{t+1}\mid s_t,s_{t-1},\ldots)=P(s_{t+1}\mid s_t)

Why it matters

The property is not a claim that history never matters. It says that an adequately defined present state contains the history information needed for the modeled transition.

MMALS relevance

If MMALS keeps only a current inferred state or belief rather than a full learning history, it must test whether that compressed object is sufficiently Markovian for its prediction and decision goals.

Toy

Create a process where the latest raw observation is ambiguous but the last two observations identify the regime. Show that the raw observation is non-Markov while an augmented state can restore the property.
