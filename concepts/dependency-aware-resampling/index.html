Dependency-aware resampling

Resampling should follow the independent scientific units and their dependence structure, not merely the rows stored in a table.

Statistical conceptreviewed 2026-08-24stable /go/ link

In plain language

If the same person appears in many comparison rows, those rows do not represent many unrelated people. Treating every row as independent can make the data look more informative than it really is.

Engineering view

In verification data, genuine and impostor trials can share identities or templates. A subject-aware bootstrap resamples the appropriate identity/template units and reconstructs the contribution of the observed trial graph. The same draw should be applied to reference and candidate routes for paired differences.

Research view

The bootstrap unit is part of the estimand's uncertainty model. A row bootstrap is valid only under a defensible row-level independence assumption. More Monte-Carlo replicates reduce simulation noise in the interval estimate; they do not create more independent subjects.

Formal anchor

resampling unit should approximate the independent data-generating unit
Historical lesson
Misconception

“10,000 pair rows means N=10,000 independent observations.” Not if the same identities recur across many rows.

Understanding gate

Given a pair table with repeated identities, identify why row resampling can understate uncertainty and propose a dependence-aware unit.

Worked example

In the Siamese Embedding Compression Lab, Study 0 replaced a pair-row bootstrap with subject-level resampling over the exact observed pair graph. The corrected intervals became materially wider while the bounded negative conclusion remained unchanged.
