Latent state

An inferred internal representation of state variables that are not directly observed.

foundational conceptadded 2026-08-30

Core idea

A latent state is useful only insofar as it preserves information required for prediction or decision. Compression alone does not make a latent vector a meaningful state.

z_t=E(o_{\le t})

Common confusion

Embedding and latent state are not automatically equivalent. A representation optimized only for current classification can discard transition-relevant information.

MMALS relevance

MMALS may eventually need host- or regime-specific latent states whose validity is tested through transition prediction, competence retention and uncertainty calibration.

Toy

Compare a classifier embedding with a transition-trained latent state on a hidden-regime toy. If both classify current observations equally but only one predicts regime changes, the distinction becomes visible.
