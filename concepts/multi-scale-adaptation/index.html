Multi-scale adaptation

Immediate response, model adaptation and structural regime change are different update scales and should not be collapsed into one mechanism.

open hypothesisadded 2026-09-03stable /go/ link

In plain language

A system can react without relearning, relearn without changing its architecture, and change architecture only when the old organization no longer fits. Those are three different kinds of adaptation.

Engineering view

Use the cheapest reversible response first: choose an action or route; then adapt parameters or local memory if evidence persists; only then transform, fork or nominate a new regime when compatibility and non-regression checks fail.

Research view

The biological analogy of reactivity, acclimation and population adaptation motivates the separation, but does not validate the computational hierarchy. MMALS should compare fixed thresholds, learned change-point policies and simpler continual-learning baselines under controlled distribution shifts.

Formal anchor

react → adapt → transform/fork → candidate new regime
open hypothesis
Current evidence

MMALS already contains the candidate sequence reuse → adapt → fork → new regime in minimal sufficient dynamic inference. The bio-inspiration source supplies an independent conceptual reason to distinguish update time scales, not evidence that the sequence is optimal.

Boundary

The levels are engineering abstractions, not a claim of one-to-one equivalence with organismal or evolutionary mechanisms.

Why it matters for MMALS

Without scale separation, every surprise risks becoming either an expensive retraining event or an uncontrolled architecture mutation. Explicit levels make escalation, evidence and rollback obligations visible.

Misconception

Wrong: adaptation always means changing model weights. Correction: an adaptive system may first change action, routing or context belief while leaving the learned model untouched.

Understanding gate

For one distribution shift, identify an action-only response, a within-model adaptation, and the evidence that would justify a structural fork.
