Adaptive planning

Contingent policy

A plan whose later actions depend on observations that have not happened yet.

planning conceptadded 2026-09-01

Intuition

A fixed action sequence says “do A, then B, then C”. A contingent policy says “do A; if I observe x, do B; if I observe y, do C”. The branching structure is the point.

\pi:\;b_t\mapsto a_t,\qquad b_{t+1}=\tau(b_t,a_t,o_{t+1})

Concrete example

Run a diagnostic probe. If it reports high risk, repair. If it reports low risk, reuse the current configuration. The plan is defined before the result, but the second action is not.

Mathematical descent

The current belief selects an action through the policy. The environment generates an observation. The Bayes/filtering update maps the old belief, action and observation to a new belief. The same policy is applied again. Repeating this loop defines a policy tree without requiring the full tree to be materialized at runtime.

In plain language

A contingent plan commits to a decision rule, not to pretending that future evidence is already known.

Misconception

Wrong: adaptive planning requires precomputing every possible branch to arbitrary depth. Correction: a controller can act, observe, update and replan over a limited horizon.

Understanding gate

Draw a two-observation policy tree and explain which parts are fixed before execution and which depend on future evidence.

Authority

POMDP policy/value framing: Kaelbling, Littman & Cassandra (1998).
