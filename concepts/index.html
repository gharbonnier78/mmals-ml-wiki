Concepts

Stable explanations for MMALS, machine-learning evaluation, geometry, memory, control, evidence governance, and the emerging dynamic-systems research bridge.

27 conceptsreviewed 2026-08-24
Architecture

MMALS

A continual-learning research program in which heterogeneous hosts exchange transformed latent signals through an adaptive, auditable medium.

Semantics

Biological mapping

A disciplined correspondence between host organisms, the fungal medium, and the mycorrhizal exchange relationship.

Architecture

Host

A specialist computational module whose value is defined by its contribution to the wider MMALS system, not only by isolated accuracy.

Architecture

Fungal medium

The active mediator that transforms, routes, allocates, remembers, and audits exchanges among hosts.

Semantics

Mycorrhizal exchange

The governed mutualistic relationship through which hosts and the fungal medium exchange useful resources or information.

Routing

Inferred context

A distribution q(c|x) over possible situations inferred from the input instead of supplied as a task identifier.

Routing

Route

The context- and input-dependent allocation of host contributions used to construct a mediated computation.

Memory

Functional route

The composed route-plus-transformation computation, not merely the vector of routing coefficients.

Memory

Functional memory

Memory that preserves a reusable computation or behavior rather than only parameters, topology, or route identity.

Memory

Reconstructive and synthetic memory

Two complementary modes: replayable route-function history for audit, and compressed reusable abstractions for efficient operation.

Ecology

Host specialization

Stable, causally meaningful differentiation of host roles across tasks, contexts, or functions.

Geometry

Probability simplex

The constrained geometric space in which non-negative route weights sum to one.

Geometry

Torus

The product of two independent periodic coordinates, S¹×S¹, and a candidate latent geometry only when the data truly carries two periodic degrees of freedom.

Continual learning

Stability–plasticity

The tension between preserving useful old functions and adapting enough to learn new ones.

Evaluation

CAL evidence layer

A five-axis evaluation layer separating Competence, Coverage, Compactness, Context, and ACTION.

Evidence governance

Outcome-bearing execution

An execution whose outputs can become scientific observations and influence a claim, estimand, gate, belief, comparison, or decision.

Control

TPUT

The MMALS system-level layer for turning goals, evidence, cost, memory, and routing into governed decisions.

System specification

EcoSpec

A minimal MMALS system contract for goal-conditioned, memory-preserving, auditable adaptive learning.

MMALS research frontier

Minimal sufficient dynamic inference

Reuse, adapt, fork, then nominate a new regime only when evidence justifies structural growth.

Dynamical systems

Stochastic dynamics

Dynamics whose model contains an explicit probabilistic component.

Dynamical systems

Deterministic chaos

An explicit deterministic model can remain hard to predict because small state errors grow rapidly.

Dynamics and inference

Dynamical regime

A persistent qualitative mode of behavior, distinct from a statistical cluster and from a causal regime.

Signal and dynamics

Observability and reconstruction

How much partial information is sufficient to recover relevant hidden state or dynamics?

Mathematical bridge

Local-to-global structure

How precise local constraints can restrict global behavior without importing unjustified physical laws.

Geometry

Local geometry

Locally simple charts, metrics and transition rules for globally complex state spaces.

Routing and regime inference

Dynamic compatibility distance

A multi-evidence compatibility signal rather than one universal latent-space distance.

Predictive models

World model

An internal predictive model of state evolution; a conditional future extension for MMALS, not a current label.
