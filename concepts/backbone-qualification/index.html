Experimental design

Backbone qualification

Before studying a downstream transformation, first show that the frozen source representation is credible for the task under a preregistered replay gate.

Design conceptreviewed 2026-08-24stable /go/ link

In plain language

If you want to know whether compression damages a face embedding, first make sure the original embedding itself is working as expected. Otherwise a bad starting point can be mistaken for a compression problem.

Engineering view

Freeze one model, its exact weights, preprocessing, dataset protocols and reproduction tolerances. Replay reference benchmarks before fitting downstream projections. If the backbone does not reproduce closely enough, stop and diagnose rather than tuning the compression stage to compensate.

Research view

Qualification reduces confounding. It separates the claim “this source representation is a credible substrate” from the later claim “this transformation preserves enough of its performance”. The two claims need different evidence and should have separate gates.

Formal anchor

qualify source substrate -> freeze PASS/FAIL/INDETERMINATE -> only then study downstream transformation
Causal discipline
Misconception

“If compression performs badly, compression must be the cause.” Not if the source representation or replay pipeline was already invalid.

Understanding gate

Explain which downstream conclusion becomes confounded when the source backbone has not first been qualified.

Connected concepts
