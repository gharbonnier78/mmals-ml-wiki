Dynamics and decision

State

A description containing the information needed to characterize the system at a given time for the evolution, inference or decision problem being considered.

foundational conceptadded 2026-08-30

Not every variable is state

State is problem-relative. A full physical description can be unnecessary, while an omitted variable can make a representation non-Markovian for the question at hand.

s_t \rightarrow s_{t+1}

MMALS relevance

The future world-model branch must specify what its state preserves: competence, uncertainty, transition structure and decision-relevant information. “State” must not become a synonym for arbitrary embedding.

Toy

A two-regime hidden process is a useful toy: ask whether the chosen state lets the model predict the next regime and choose the correct action without retaining the full history.
