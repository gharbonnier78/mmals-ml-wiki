Markov decision process (MDP)

A model of sequential decision making with states, actions, transition dynamics and rewards or costs under a Markov-state assumption.

foundational conceptadded 2026-08-30
P(s_{t+1}\mid s_t,a_t)

Core objects

An MDP usually specifies state space, action space, transition model, reward/cost and a policy. Full observability of the modeled state is assumed.

Boundary

If the relevant state is hidden and only indirect observations are available, a POMDP is often the more appropriate abstraction.

MMALS / ED-POMDP relevance

MDPs provide a clean reference for separating state inference from action selection. ED-POMDP is the project-specific Evidence-Driven POMDP research programme; the GO-ED wording used in this wiki refers only to a tentative goal-oriented extension of that programme, not to an established external framework.

Toy

A two-state maintenance controller with known state is a minimal MDP toy. Hide the state and add noisy measurements to turn the same toy into a POMDP.
