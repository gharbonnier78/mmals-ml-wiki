Brier score

A squared-error score for probabilistic forecasts; this page explicitly uses the normalized binary one-component convention.

foundational scoring rulerevised 2026-09-26stable /go/ link

Discover

Say 80% and the event happens: your probability error is small. Say 20% and it happens: the error is large.

Engineer

For y∈{0,1}, this project uses BS(p,y)=(p−y)². Lower is better. Always state the convention when comparing external results.

Research

Brier's 1950 multicategory index sums squared errors over categories. For a binary two-category vector that sum equals 2(p−y)². Many modern binary applications use the normalized one-component form shown here.

Formal anchor

BS(p,y)=(p-y)^2

Concrete example

If y=1, BS(0.8,1)=0.04 while BS(0.2,1)=0.64 under this normalized convention.

Misconception

Wrong: a lower Brier score on one event proves a method is superior. Correction: one event supplies one paired observation; method comparison needs a suitable prospective event set and dependence-aware uncertainty analysis.

Understanding gate

Compute BS(0.7,0), then explain why an external paper using the original two-category sum would report twice this binary value.
