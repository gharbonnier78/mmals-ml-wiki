Brier score

Squared-error scoring of probability forecasts; this project states the normalized binary convention explicitly.

foundational scoring rulerevised 2026-09-26stable /go/ link

Discover

The score squares the distance between the probability you announced and the 0/1 outcome that occurred.

Engineer

This project uses the normalized binary one-component loss. Brier's original two-category vector sum equals twice this quantity for a binary event.

Research

Brier loss is proper for binary probability forecasts; method comparisons still require prospectively sampled events and dependence-aware uncertainty.

Formal anchor

BS(p,y)=(p-y)^2

Concrete example

If y=1, BS(0.8,1)=0.04 while BS(0.2,1)=0.64 under this normalized convention.

Misconception

Wrong: a lower Brier score on one event proves a method is superior. Correction: one event supplies one paired observation; method comparison needs a suitable prospective event set and dependence-aware uncertainty analysis.

Understanding gate

Compute BS(0.7,0), then explain why an external paper using the original two-category sum would report twice this binary value.
