Minimal sufficient dynamic inference

A candidate MMALS principle: preserve the smallest auditable inference system that remains sufficient for demonstrated situations, and increase structural complexity only when evidence requires it.

open hypothesisadded 2026-08-24

In plain language

Do not create a new model merely because new data arrived. First reuse what already works. If needed, adapt it without materially losing old competence. Fork only when specialization is justified. Create a candidate new regime only when existing hosts are no longer compatible with the evidence.

REUSE \rightarrow ADAPT \rightarrow FORK \rightarrow CANDIDATE\ NEW\ REGIME

Competence contract

An adaptation should improve or satisfy the new target while keeping previously demonstrated competence within an explicit tolerance. This is a testable non-regression contract, not a promise of perfect monotonic learning.

L_{old}(H^{t+1}) \le L_{old}(H^t)+\epsilon

Minimal does not mean tiny

System complexity may include host count, parameters, routing cost, memory, replay, latency, energy and human audit burden. The target is minimal sufficient complexity, not minimal parameter count.

Failure conditions

This principle should be rejected or narrowed if adaptive forks grow without measurable benefit, if fixed MoE or standard continual-learning baselines perform as well at lower cost, or if novelty decisions are mostly artifacts of representation distance.

Evidence status

Current evidence

Conceptual synthesis and continuity with existing MMALS work on inferred context, functional memory, specialization and stability-plasticity.

Boundary

No comparative experiment yet establishes this lifecycle as better than simpler continual-learning or mixture-of-experts strategies.
