Predictive models

World model

An internal predictive model of how relevant state evolves, often conditioned on actions, that supports prediction, simulation, planning or control.

general conceptMMALS relation conditionaladded 2026-08-24

Minimal definition

A model becomes world-model-like when it represents enough latent state and transition structure to predict meaningful future consequences rather than only map current input to current output.

p(s_{t+1}\mid s_t,a_t)

Not every world model uses this exact probabilistic form, and not every predictive model is sufficient for planning or control.

MMALS boundary

Adaptive routing, inferred context or regime creation do not by themselves make MMALS a world model. The connection becomes substantive only if MMALS learns and validates predictive transition dynamics and, where relevant, action-conditioned outcomes.

Why the connection is interesting

A regime-aware, compact, auditable model that preserves old competence while learning transition structure could become a useful systems-engineering world model. That remains a future objective, not a present claim.
